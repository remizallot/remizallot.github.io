The [Enzyme Function Initiative (EFI)](/portfolio/efi-web-tools/) genomic enzymology web tools have been relaunched at [efi.igb.illinois.edu](https://efi.igb.illinois.edu/). With the [2.0 release](https://github.com/EnzymeFunctionInitiative/EST/releases/tag/2.0), the software behind the tools has been rewritten and modernised.

The tools still support the same genomic enzymology approach, which combines sequence similarity with genome context to explore protein families. They allow users to easily create and exploit sequence similarity networks (SSNs), genome neighbourhood networks (GNNs) and genome neighbourhood diagrams (GNDs). Researchers can use them to propose new biological functions for uncharacterised proteins, and to draw on what is known about an enzyme family for biotechnological applications.

If you used the tools before, you will need to create a new account on the new website. Please do not hesitate to contact the EFI team if you have any questions. Work is led by Nils Oberg with Russell Davidson and Hunter DeMeyer. John Gerlt and I provided scientific guidance. The work was funded by the National Institutes of Health/National Institute of General Medical Sciences (grant R24GM141196 to John A. Gerlt).
