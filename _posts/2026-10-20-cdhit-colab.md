The CD-HIT web server has been unavailable since 2022. As an alternative, I have released [CD-HIT in Google Colab](/portfolio/cdhit-colab/), a notebook that builds CD-HIT from source and clusters your sequences in the browser. You don't need to install anything.

The parameters are set through form fields with explanatory notes, and every run records its own provenance (CD-HIT version, command line, input checksum and timestamp), so results are easy to reproduce and report.

If you use it, please cite CD-HIT and the notebook: [10.5281/zenodo.23503573](https://doi.org/10.5281/zenodo.23503573).
